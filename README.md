# YNAB CSV Parser

A modern, fully packaged pipeline that converts OCBC and POSB transaction exports
into YNAB-compatible CSVs and optionally uploads them to YNAB.

## Features

-   Unified CLI: `python -m ynab_parser <command>`
-   Structured logging, rich validation, and detailed errors
-   Extensible parser factory (add more banks without touching the CLI)
-   Transaction uploader with dry-run previews and retry-aware YNAB API client

## Quick Start

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install -r requirements.txt

# 1. Configure credentials (.env)
python -m ynab_parser setup --config .env

# 2. Parse every CSV under data/incoming and save normalized output
python -m ynab_parser process --input data/incoming --output results

# 3. Preview uploads
python -m ynab_parser upload --config .env --dry-run

# 4. Push to YNAB
python -m ynab_parser upload --config .env
```

Default locations:

-   Input CSVs: `data/incoming/**`
-   Normalized CSVs: `results/*.csv`
-   Config: `.env` (generated by the setup wizard)

## Command Reference

### Setup

```
python -m ynab_parser setup --config .env
```

-   Prompts for YNAB API token, default budget, and account mapping
-   Writes `.env` with everything the processor/uploader need

### Process

```
python -m ynab_parser process --input data/incoming --output results \
    --bank posb --bank ocbc      # optional filters
```

-   Discovers CSVs under the input directory (recursively)
-   Runs the appropriate parser (POSB, OCBC, …)
-   Produces YNAB-format CSVs such as `results/posb_default_12-2025_01-2026.csv`

### Upload

```
python -m ynab_parser upload --config .env --results results \
    --dry-run                    # omit for a real upload
```

-   Loads CSVs created by `process`
-   Converts rows to YNAB transactions and pushes them through the API client
-   Supports `--account` overrides and per-file filtering

## Troubleshooting

| Symptom                  | Fix                                                                                                           |
| ------------------------ | ------------------------------------------------------------------------------------------------------------- |
| No transactions detected | Confirm files live under `data/incoming/**`, match POSB/OCBC formats, and are UTF-8 encoded.                  |
| Date parse warnings      | Ensure bank exports are unmodified; POSB should look like `10 Jan 2026`, OCBC like `10/01/2026`.              |
| Upload errors            | Re-run `python -m ynab_parser setup` to refresh API tokens, or pass `--dry-run` to inspect CSV content first. |
